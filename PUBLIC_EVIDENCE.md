# Public evidence package

This repository contains the toolkit, the three required write-ups, and selected task-specific evidence. Full chat-session JSONL logs, internal writing/checklist files, and development environments are excluded. Personal machine paths in copied text records were replaced with repository-relative paths or placeholders; tool results, reported measurements, and reviewer judgments were otherwise preserved. Only game screenshots are included.

Actual native call excerpts are in evidence/native-tool-excerpts.md. Earlier reports refer to historical versions; the final student-approved layout is shown in evidence/user-feedback/. Local development retained the original complete records separately.
